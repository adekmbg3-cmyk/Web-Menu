FAQ

Pertanyaan yang Sering Diajukan

Belum menemukan jawaban? Hubungi kami langsung melalui WhatsApp atau email.

Untuk paket Basic rata-rata 7 hari kerja, paket Pro 14 hari kerja, dan paket Enterprise 21 hingga 30 hari kerja tergantung jumlah halaman dan sesi foto. Waktu mulai dihitung setelah brief dan DP diterima.

Ya. Kami sudah menangani klien dari berbagai kota di Indonesia. Seluruh proses konsultasi, review desain, dan revisi dapat dilakukan secara online melalui video call dan email.

Setiap paket sudah termasuk file siap cetak beresolusi tinggi. Untuk file kerja mentah dalam format AI atau PSD, tersedia pada paket Pro dan Enterprise.

Paket Basic mendapat 2 kali revisi, paket Pro 5 kali revisi, dan paket Enterprise mendapatkan revisi tanpa batas selama lingkup proyek tidak berubah secara fundamental.

Harga paket hanya mencakup jasa desain, foto, dan penyiapan file cetak. Biaya cetak fisik dihitung terpisah sesuai jumlah halaman, jenis kertas, dan finishing yang dipilih.

Pembayaran dibagi dua tahap, yaitu 50 persen sebagai uang muka saat proyek dimulai dan 50 persen sisanya saat desain final disetujui sebelum file dikirim.
